# Contributing

Keep changes small, tested, and inside v0's stated trust boundaries.

1. Open an issue describing the behavior or security invariant.
2. Run `npm test` before and after the change.
3. Add the smallest test that would fail if the invariant regressed.
4. Do not add payment execution, credentials, speculative provider abstractions, or browser-authoritative permission state.
5. Confirm that contributed code and assets are yours or compatible with Apache-2.0.

By contributing, you agree that your contribution is licensed under Apache-2.0.
